# 将棋アプリ「KomaPal Shogi（コマパル しょうぎ）」設計書

版: 0.4（2026-10-26）CPU レベルを 10 段階に変更 / 対象: Claude Code による実装

## 0. 決定事項（v0.1 からの変更）

| 論点 | 決定 |
|---|---|
| 公開形態 | **最終的に URL で誰でも遊べる**公開サイト |
| 構成 | **ブラウザだけで完結する静的サイト**（サーバ不要）。将棋の思考も遊ぶ人の端末内で動かす |
| 公開先 | GitHub Pages（第1候補）／Cloudflare Pages（代替） |
| 言語 | アプリ本体は **TypeScript**。Python は開発用ツール（ルール検証・強さ測定・イラスト生成）に使用 |
| ライセンス | GPLv3 で公開（了承済み） |
| 待った | 無制限 |
| 主な利用者 | **将棋を始めたばかりの子ども**。ふりがな・駒の動きガイド必須 |
| 駒落ち | 不要 |

### 構成を変えた理由

Python サーバを公開サーバに置く案は、無料枠だと実用に耐えません。たとえば Render の無料枠は 15 分アクセスが無いと停止し、次のアクセス時に起動まで約 1 分待たされ、CPU は 0.1 個分です。子どもが開いて 1 分待つのは厳しく、強い CPU の思考も遅くなり、同時に何人も遊ぶと詰まります。

静的サイト＋ブラウザ内エンジンなら、**サーバ代 0 円・待ち時間なし・利用者が何人でも平気**（計算は各自の端末）、iPad やスマホでもそのまま遊べます。

## 1. 目的・概要

- 将棋を覚えたての子どもが、楽しく・くじけずに上達できる CPU 対戦将棋。
- 駒の動きガイド、ふりがな、やさしい言葉の解説で「ひとりでも学べる」。
- 大人も楽しめるよう、最強レベルは十分強く。

## 3. ルール仕様（全レベル共通・必須）

判定は**ルールライブラリ（shogiops）＋自前の補完モジュール `rules/` だけ**で行い、CPU は必ず合法手リストから手を選ぶ。

| ルール | 扱い |
|---|---|
| 駒の動き・成り | 敵陣 3 段に入る/出る/中で動くとき成り選択。行き所のない駒は強制成り |
| 持ち駒を打つ | 空き升のみ。行き所のない升には打てない |
| 二歩 / 打ち歩詰め | 禁止（突き歩詰めは可） |
| 王手放置・自殺手 | 禁止 |
| 詰み | 負け |
| 千日手 | 同一局面 4 回で引き分け。連続王手の千日手は王手側の反則負け |
| 入玉宣言 | 27 点法（大人向けメニューに配置） |
| 投了 | 人は投了ボタン。CPU はやねうら王のレベル（L8〜10）のみ投了 |

ライブラリが未対応のルール（千日手・入玉宣言など）は `rules/` に自作し、**Python の cshogi と突き合わせる検証テスト**（多数のランダム局面で合法手の一致を確認）で品質を担保する。

### 公開時の技術的注意

- WebAssembly 版エンジンはマルチスレッドのため、ページが「クロスオリジン分離」状態である必要がある（HTTP ヘッダ COOP/COEP）。
  - GitHub Pages はヘッダを設定できないので、**coi-serviceworker**（ヘッダを補うスクリプト）を同梱して対応。
  - うまくいかない場合は Cloudflare Pages（`_headers` ファイルでヘッダ設定可）に切替。
- 上記の都合で、外部サイトのフォント・画像は読み込まず**すべて自前配信**にする。
- エンジンが使えない端末（古いブラウザ等）では自作αβに自動切替し、「かんたんモードで動いています」と表示。

### 評価関数ファイルについて（重要）

公開サイトでは、評価関数ファイルも利用者のブラウザに配信されます（＝再配布）。前回「同梱しない」で了承いただきましたが、公開サイトでは同梱が避けられないため方針を次のとおりとします。

1. **初版は評価関数を使わない駒得版**のやねうら王を使う（許諾問題なし）。子ども〜一般の大人には十分強い。
2. 評価関数付き版（さらに強い）は、配布元の再配布条件を確認できてから切り替える。

## 5. CPU レベル設計

新規対局画面では 3 つのグループに色分けして並べる（はじめて＝緑、れんしゅう＝青、ちょうせん＝赤）。各レベルに 10 本のつよさメーターを付ける。

| Lv | グループ | 名前 | アイコン | 方式 |
|---|---|---|---|---|
| 1 | はじめて | ひよこ | 🐥 | こども AI: 合法手からほぼランダム。タダの駒は 35% だけ取る。1 手詰めは 15% しか気づかない。タダで取られる手・意味のない王の前進はときどきだけ避ける |
| 2 | はじめて | ハムスター | 🐹 | こども AI: 1 手読み＋駒得評価＋大きめのゆらぎ。1 手詰めは見逃さない |
| 3 | はじめて | うさぎ | 🐰 | こども AI の最強版: 1 手読み・ゆらぎなし（同点の手は乱数で選ぶ）・1 手詰めは必ず指す・指した駒がタダで取られる手は必ず避ける |
| 4 | れんしゅう | ねこ | 🐱 | 自作αβ 深さ 1＋ゆらぎ 30・取り合い（静止探索）2 手 |
| 5 | れんしゅう | カピバラ | 🦫（カピバラの絵文字が無いのでビーバー） | 自作αβ 深さ 2＋ゆらぎ 150・取り合い 1 手 |
| 6 | れんしゅう | しばいぬ | 🐕 | 自作αβ 深さ 2・ゆらぎなし・取り合い 2 手 |
| 7 | れんしゅう | ふくろう | 🦉 | 自作αβ 深さ 3＋ゆらぎ 80・取り合い 2 手（3 秒で打ち切り。1 秒では深さ 3 を読み切れない局面が多く、L6 と同じ強さになってしまうため） |
| 8 | ちょうせん | ツキノワグマ | 🐻 | やねうら王 少ノード（3,000）＋ MultiPV 4 の候補からゆらぎ選択 |
| 9 | ちょうせん | ライオン | 🦁 | やねうら王 中ノード（300,000） |
| 10 | ちょうせん | ドラゴン | 🐲 | やねうら王 1 手 3 秒（遅い端末は 1.5 秒ぶんの局面数で打ち切る） |

- 目標: 隣どうしのレベルで、上のレベルの勝率が 7〜9 割（全勝にはならない）。パラメータは `src/ai/levels.ts` に集約（遊びながら調整）。
- 自作αβ（L4〜7）は、読む深さより「取り合いを何手先まで読むか（静止探索）」で強さが大きく変わる。ゆらぎの効きは小さい。そのため、深さと静止探索の組み合わせで段差をつけている。
- 自作αβは同点の手を乱数で選ぶ（同じ手を繰り返して千日手になるのを防ぐ）。
- CPU の投了はやねうら王のレベル（L8〜10）だけ。
- 思考は最低 0.6 秒（瞬間指しは子どもが手を追えない）。CPU の手は駒がスッと動くアニメーション。
- 名前・アイコンは子どもに分かりやすく（数字と併記）。説明文はやさしい言葉＋ふりがな。

|---|---|---|
| L2 vs L1 | 100% | ✗（L1・L2 は数字を変えない方針のため調整していない） |
| L3 vs L2 | 95% | ✗（同上） |
| L4 vs L3 | 80% | ✓ |
| L5 vs L4 | 85% | ✓ |
| L6 vs L5 | 85% | ✓ |
| L7 vs L6 | 85%（27 局。途中で止まった 2 回ぶんを合わせた） | ✓ |
| L8 vs L7 | 75% | ✓ |
| L9 vs L8 | 100% | ✗（フェーズ4で測定。エンジンの数字は変えない方針） |
| L10 vs L9 | 100% | ✗（同上） |

### かんたんモード（やねうら王が使えない端末）

L8〜10 も選べるままにし、やねうら王の代わりに自作αβで指す。画面上部に「かんたんモードで動いています」、新規対局画面の L8〜10 に「いまはかんたんモードでうごくよ」と表示する。投了の条件はふつうと同じ（評価値 −3000 以下が 2 手続いたら）。

| Lv | かんたんモードでの方式 | 一つ下に勝った割合（各 20 局） |
|---|---|---|
| 8 ツキノワグマ | 自作αβ 深さ 3・ゆらぎなし・取り合い 3 手（4 秒で打ち切り） | L7 に 70%（10 局） |
| 9 ライオン | 自作αβ 深さ 3・取り合い 4 手（5 秒で打ち切り） | かんたんモードの L8 に 70%（10 局） |
| 10 ドラゴン | 自作αβ 深さ 3・取り合い 5 手（6 秒で打ち切り） | かんたんモードの L9 に 60%（10 局） |

- 自作αβは駒得だけの評価なので、やねうら王の L8〜10 よりはずっと弱い。1 手に数秒かかることがある。
- 深さ 4 は数秒では読み切れないことが多いため、L9・L10 の差は取り合いを読む手数でつけている。L10 と L9 の差は小さい（60%）。
- かんたんモードの自己対局は 1 局 5 分ほどかかるため、各 10 局で測った。

## 6. 形勢ゲージ・サポート

### 6.1 形勢ゲージ

- 最上部の横バー。左＝あいて、右＝じぶん。中央に勝率%と評価値（例 `+350`）。
- 子ども向け表示: 数値の横に顔マーク（😊 有利 / 😐 互角 / 😟 不利）と一言（「いいかんじ！」「ピンチ！」）。
- 勝率 = 1 / (1 + exp(−評価値 / 600))、プレイヤー視点。詰みが見えたら「あと 5 手でつむ」。
- 設定で非表示可。

### 6.2 次の一手提案（サポートモード）

- 自分の手番でエンジンを MultiPV=3 で解析し、候補 3 手をカード表示。
- おすすめ度: ★★★（最善との差 50 点以内）/ ★★（200 点以内）/ ★、指した後の勝率。
- 理由: ルールベースで 1〜2 文。**子ども向けのやさしい言葉**（ふりがな付き）。

| 特徴 | 文例 |
|---|---|
| 詰み | 「この手から 5 手で、あいての王さまをつかまえられるよ！」 |
| 王手 | 「王手！王さまをおいつめよう」 |
| 駒得 | 「あいての銀をタダでとれるよ」 |
| 成り | 「角がなって『馬』になるよ。もっとつよくなる！」 |
| ねらい | 「つぎに飛車と金を両方ねらえるよ（りょうどり）」 |
| 守り | 「とられそうな金をまもるよ」「王さまのまもりをかためよう」 |
| 受け | 「あいての王手をふせぐよ」 |

- カードを押すと盤上に矢印。もう一度押すとその手を指す（誤タップ防止の 2 段階）。
- 段階ヒント（設定）: 「ヒント1: うごかす駒だけ光る」→「ヒント2: 手を全部見せる」。
- 悪手アラート: 勝率が 20% 以上下がる手を指したら「いまの手、あぶないかも。まったする？」。

## 12. 受け入れ基準

- 全レベル CPU 同士 100 局で反則 0。
- Python（cshogi）とのルール照合: ランダム局面 1 万件で合法手が完全一致。
- 強さの順序: 隣どうしのレベルで、上のレベルの勝率が 7〜9 割（自己対局 各 20 局）。結果は 5 章。L1 の強さは勝率で縛らず、人が遊んで判断する（ランダム AI との勝率は基準にしない）。
- 家族の確認: 覚えたての子が L1 に勝てる、L2 と勝ったり負けたり。
- Windows（Chrome/Edge）、iPad（Safari）、Android（Chrome）で対局〜終局まで操作可能。
